# 基于SpringBoot+Vue3的酒店客房管理系统

![Spring Boot](https://img.shields.io/badge/-Spring%20Boot-6DB33F?style=flat-square&logo=spring-boot&logoColor=white) ![Vue3](https://img.shields.io/badge/-Vue3-grey?style=flat-square) ![ElementPlus](https://img.shields.io/badge/-ElementPlus-grey?style=flat-square) ![MySQL](https://img.shields.io/badge/-MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white) 

## 项目介绍

一套完整的酒店客房管理系统，涵盖客户端和管理后台两套界面。客户端支持客房浏览、房间详情查看、在线预订、订单查询、评价管理等功能；管理后台提供用户管理、房型管理、房间管理、预约审核、订单管理、退房管理、客房服务、轮播图管理、酒店信息管理及数据统计仪表盘等模块。

## 功能模块

- **用户管理**：注册登录、个人信息编辑、密码修改、角色权限控制
- **客房展示**：房型分类浏览、房间详情、图片轮播展示
- **在线预订**：选择房型日期、提交预订申请、预约状态跟踪
- **订单管理**：订单生成、支付状态管理、退款处理、订单统计
- **评价管理**：入住评价、评分系统、评价审核
- **退房管理**：退房申请、退房审核流程
- **客房服务**：在线提交服务请求、服务状态跟踪
- **数据统计**：仪表盘展示用户数、订单数、营收趋势图表

## 技术架构

- **后端**：Spring Boot 2.7.18 + MyBatis-Plus 3.5.7 + Spring Security + JWT 认证
- **前端**：Vue 3 + Element Plus 2.9.4 + Vue CLI 5 + ECharts 6 + Pinia
- **数据库**：MySQL 8.0
